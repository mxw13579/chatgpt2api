# R2 图片存储使用说明

## 行为

- Images 默认或 `response_format=b64_json`：只返回 Base64，不上传、不写本地图片。Chat/Responses 图片同样不保存。
- Images `response_format=url` 及网页图片任务：按当前存储模式保存。R2 模式从启用、防护和用量均有效且预算足够的账号中随机选择；每图一次 PUT。
- R2 模式只保存图片索引、账号配置、用量状态和任务引用，不生成本地原图或缩略图。网页直接访问自定义域名，不通过 Worker 或应用匿名代理。
- 没有可分配账号、预算不足或上传失败时明确失败，不回退本地/WebDAV，也不将 URL 请求改成 Base64。上传结果不确定时保留对象 key 和容量预占，到期后删除。
- 现有 local/WebDAV/both 模式保留；Base64 不保存的规则适用于所有模式。

## 接入步骤

在 **设置 → 图片存储** 中单独保存；基础设置保存不会覆盖图片存储。

1. 在 Cloudflare 账号中准备一个 **Standard 专用图片桶**，不要使用备份桶。先把准备绑定的域名接入同一账号的 Zone；本项目不负责域名购买、续费和外部 NS 修改。
2. 添加账号草稿，填写 CF Account ID、桶名、S3 Access Key/Secret、CF 管理 API Token。新账号默认不参与分配，可先保存不完整草稿。
3. 设置容量/A/B 预算，核对该账号实际计费周期的 UTC 起始日并勾选确认。默认周期日仅是表单初值，不代表已查询账户账单。
4. 保存后执行连接测试，读取同账号 Zone，绑定域名。新域名初始停用；等待 CF 所有权及 SSL 激活。
5. 点击 **应用防护与 CORS**：创建/更新本项目的免费规则，关闭 `r2.dev` 和未纳管的公开绑定。应用失败可能关闭该桶全部公开入口，页面会显示错误；不会删除其他规则或自动升级付费。
6. 启用受保护的域名，设为当前域名；按相同方式添加备用域名。没有图片时显示“无探测样本”，不会为了探测上传图片。
7. 刷新账号用量；统计完整、防护就绪后，勾选参与分配，选择 R2 模式并保存。

### 凭据与权限

- S3 凭据：限定专用图片桶的对象读写和必要列表权限。连接测试发送一次 LIST，会预记一次 A 类操作。
- CF Token：限定对应账号及 Zone，需要读取 Analytics、读取 Zone，以及管理 R2 桶的自定义域名、managed domain、CORS 和对应 Zone 的 WAF/Rate Limiting/Cache Rules 权限。具体权限名称以 CF 创建 Token 页面与当前 API 要求为准，不使用 Global API Key。
- 界面不回传三项 R2 凭据，只显示已配置标记；空白或省略表示保留旧值，可填入新值轮换。
- 连接测试成功只证明已执行的对象 LIST、Zone/域名读取成功，不代表 Analytics 或规则写入权限已全部验证。
- 配置文件仍包含私密凭据，按现有配置备份方式保管。不要将配置、Token 或签名请求贴进日志或公开问题报告。

## 预算与用量

默认每账号：容量预算 8 GB、A 类 80 万次/周期、B 类 700 万预警、800 万保护。可以在页面修改。

- A 类计数在发出请求前持久化，失败不退款；包括上传、连接 LIST 和保守计入的 CORS 写入。云端查询与本地累计分别合并，不把两个完整总量相加；查询期间的新操作保留。
- 容量包括在存和 pending 预占，并参考云端账号容量以及图片桶实际观测时间之后的上传增量。并发预占与配置身份变更使用同一进程锁。
- 每 5 分钟刷新账号总量和图片桶用量，默认超过 15 分钟不再分配新上传。查询失败保留旧计数；不完整数据不能显示为确认的零用量。
- 已有图片的账号即使停止新分配，仍刷新用量。切回其他存储模式后，保留的 R2 账号和图片也继续维护。
- 达到 B 保护阈值先停止应用读写，再尝试关闭桶上**实际存在的全部自定义域名和 r2.dev**；失败会显示哪些入口未关成功，下个正常维护周期继续处理。
- 恢复公开访问必须显式操作，并重新检查用量和防护。切换当前域名、重新启用账号或统计波动都不会自动解除停读。

这是预算保护，不是 Cloudflare 账单硬封顶。Analytics 有延迟，其他桶/外部 S3 客户端也会消耗额度；存储免费量是 GB-month，短期删除不能撤销当天峰值。首次空桶如果尚无存储观测，界面会显示统计不完整，需要等待可用统计，不能手工把缺失数据视为零。

## 域名切换与防刷

首版是**页面手动切换＋按需检查**，没有自动故障转移或多地区探测。

- 当前域名与备用域名指向同一个桶，切换不搬图、不重置用量。
- 管理页、网页历史任务及引用通过图片 ID 解析当前 URL。外部已经复制的旧 URL 无法自动改写。
- 服务器检查与当前浏览器检查分别显示来源、时间和错误；不把单点失败认定为“被墙”。
- Free 模板按 `/images/` 路径进行每 IP/10 秒限速，默认 120 次、Block 10 秒；同 Zone 共用规则。对象前缀固定 `images/`，不能自定义为未受保护路径。
- 多个备用域名属于不同 Zone 时分别配置规则。同 Zone 上其他业务的 `/images/` 路径也可能受该限速规则影响，建议使用图片专用 Zone。
- 免费规则名额被占用或权限不足时显示失败，需管理员处理。人机挑战不作为图片接口默认动作。
- CORS 允许 GET/HEAD，可填应用 Origin 或 `*`。它用于浏览器读取/编辑/下载，不承担防刷职责。
- 账号有待上传或未删除图片时，不能换 CF Account ID、换桶或移除凭据；可以轮换同一位置的密钥、换域名或停止分配。

## 过期、缓存和旧数据

默认图片保留 60 分钟，每 60 秒处理一批最多 100 个到期对象。删除成功才释放本地容量；失败保留记录。积压或网络故障时可能超过一分钟，页面手动清理返回剩余积压数量。

默认对象头：

```http
Cache-Control: public, max-age=0, s-maxage=60, must-revalidate
```

防护模板让边缘和浏览器尊重源站响应头，不配置 Free 的长 Edge TTL 覆盖。无积压且网络正常时，目标为到期后约 1～2 分钟停止新的公网读取；这不是精确到秒的保证。用户已下载的副本不可撤回。R2 图片内容不进入本项目网页的持久图片缓存。

- 修改保留时间或缓存 TTL 只影响之后上传的图片，不回写旧对象。
- 切换模式不会自动删除旧本地图。**显式清理旧本地图/任务图片内容**会删除原有本地原图、缩略图及旧任务内嵌图片，不删除 R2 或 WebDAV 远端对象；此操作不可恢复。
- 首版不提供历史图片批量迁移 R2。要保留旧图，请先自行备份再显式清理。
- ZIP 下载在内存读取、打包，不落盘；消耗 GET，额度停读时也拒绝取图。

## 验证及尚需云端验收的部分

自动测试使用临时源码副本、合成配置及网络 mock，真实配置和图片目录不参与测试。测试覆盖预算并发、pending、配置约束、完整接入流程、域名切换、B 停读/恢复、到期清理、Base64 不保存和历史结果解析。

部署前仍需用测试桶验证实际 Token 权限、CF Analytics 数据、域名激活、Free 规则名额、CORS 和实际 `Cache-Control`/`Age`/缓存状态。没有用户云凭据时，代码及 mock 测试不能证明真实 CF 行为已验收。实施期间没有上传、删除或绑定真实 Cloudflare 资源。
